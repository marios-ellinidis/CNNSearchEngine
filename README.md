Στο  Brunch  αυτό θα βρείτε τον πηγαίο κώδικα  rag.py  και το  requirements.txt . 
Στον προσωπικό σας υπολογιστή στο terminal  πληκτρολογείστε τα εξής
1. python -m venv venv
2. venv\Scripts\activate
3. pip install -r requirements.txt

Ετσι θα βρίσκεστε στο περιβάλλον με όλες τις απαραίτητες βιβλιοθήκες για να τρέξερε το πρόγραμμα
Αφού γίνουν  install  όλα τα απαραίτητα πακέτα μπορείτε να τρέξετε τον κώδικα απλά με python rag.py
Μόλις τρέξετε τον κώδικα θα πάρει λίγο χρόνο για να δημιουργηθούν τα  embeddings  των chunks ,  θα αναγράφεται το process για να μπορέσετε να εκτιμήσετε τον χρόνο
Μετά απο λίγο θα σας εμφανιστεί αυτό: Enter your query: , απλά γράψτε οποιαδήποτε ερώτηση
Απαραίτητη πρυπόθεση να έχετε κατεβάσει το ollama και να έχετε κάνει pull και να έχετε ενα terminal ανοιχτό που να έχετε τρέξει την εντολή 'ollama serve' ,εγώ συγκεκριμένα στον κώδικα μου χρησιμοποιώ  το llama3.2:1b

Μετά την πληκτρολόγηση της ερώτησης πατήστε enter , θα εμφανιστούν σχεδόν απευθείας τα  k  relevant chunks , έπειτα το query  θα γίνει αρχικά απευθείας στο llm χωρίς context  απο την "βάση δεδομένων"
Αμέσως μετά απο θα γίνει το ίδιο query με την αρχιτεκτονική rag υποβοηθούμενο απο τα relative chunks  για να μπορουμε να το συγκρίνουμε με την πάνω περίπτωση
Ο κώδικας βρίσκεται σε ένα συνεχώμενο while loop  για να κάνετε όσες ερωτήσεις θέλετε
